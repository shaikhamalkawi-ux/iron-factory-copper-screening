# V22 additional analyses

These files document analyses added after the original public release.

- `incremental_distance_xlf_loocv.csv`: leave-one-out log-scale RMSE for the distance-only and distance+XLF Cu models, under the declared workbook and the record-17 zero-distance provenance sensitivity.
- `record17_zero_distance_k8.csv`: k=8 Cu retention values for the declared workbook and the record-17 zero-distance sensitivity.

These are exploratory finite-record diagnostics. They are not calibrated field-prediction models, population uncertainty estimates, or corrections to `source/Iron Factory.xlsx`. The source workbook remains unchanged.
